How to use this CSSBuy spreadsheet

  1. Save the original listing

    Record the HipobuyFind item ID, the original marketplace URL if available, and the exact size and color you want. Use the original marketplace URL to check whether your chosen agent can import it.

  2. Check measurements and photos

    Compare the seller’s size chart with a similar item you own. If warehouse QC photos are available, check the size label, color and measurements against your selected option before approving shipment.

  3. Compare parcel quotes

    Check the shipping line’s billed weight, tracking and restrictions. For bulky items, compare quotes with and without optional packaging before confirming the parcel.

Does this catalog show live CSSBuy inventory?

The catalog is a snapshot of HipobuyFind listings. Check the merchant page for stock and current pricing, and verify whether CSSBuy supports the original marketplace link before placing an order.

What is included in the USD price on each card?

The card converts the listed item price to an approximate USD amount. Use the worksheet to add delivery, service fees and any applicable taxes or duties.

What should I do if a product link stops working?

Search HipobuyFind with the item ID and a short product name. If you find a replacement listing, recheck the seller, size chart and price before ordering.
